# 採用エントリーフォーム 設定手順（MOONさん作業）

`recruit.html`（サイト側）と `Code.gs`（受信側）をつなぐための手順です。
所要 約10分。**メール通知だけなら LINE の設定はスキップOK**（それでも「応募がGmailに届く→定型文で返信」は完全に動きます）。

---

## STEP 1. スプレッドシートを作る
1. https://sheets.google.com で空のスプレッドシートを新規作成
2. 名前を「むーん採用エントリー」などに（任意）

## STEP 2. Apps Script を貼る
1. そのシートで上部メニュー **拡張機能 → Apps Script** を開く
2. 出てきたエディタの中身を全部消して、`Code.gs` の内容を丸ごと貼り付け
3. 上部の `CONFIG` は基本そのままでOK（通知メール先は `undouryoikumoon@gmail.com` 済）
4. 保存（フロッピーマーク）

## STEP 3. ウェブアプリとして公開（デプロイ）
1. 右上 **デプロイ → 新しいデプロイ**
2. 歯車 → 種類 **「ウェブアプリ」** を選択
3. 設定：
   - 実行するユーザー：**自分**
   - アクセスできるユーザー：**全員**
4. **デプロイ** → 初回は権限承認（自分のGoogleアカウントで許可）
5. 表示される **ウェブアプリ URL（.../exec で終わる）** をコピー

## STEP 4. サイトにURLを貼る
1. `moon-lp/recruit.html` を開く
2. 下の方の以下の行を探す：
   ```js
   var GAS_ENDPOINT = "";
   ```
3. `""` の中にコピーしたURLを貼る：
   ```js
   var GAS_ENDPOINT = "https://script.google.com/macros/s/AKfy..../exec";
   ```
4. 保存

## STEP 5. デプロイ（公開）
ターミナルで：
```bash
cd /Users/ogita/Desktop/ai実験用/moon-lp
bash push.sh "採用エントリーフォーム追加"
```

## STEP 6. テスト
- https://www.et-moon.com/recruit.html を開いてテスト送信
- ✅ Gmail（undouryoikumoon@gmail.com）に通知が来る
- ✅ スプレッドシートに1行増える

## LINE通知の設定（今回はこれも含める）

応募が来たらLINEにも通知が飛ぶようにします。
**大事な選択が1つ**あります → どのLINE公式アカウントから通知するか。

### 🔸 まず決める：どのアカウントを使うか

| | A案：むーん専用を新規作成（推奨） | B案：既存の通知ハブを流用 |
|---|---|---|
| アカウント | むーん用のLINE公式アカウントを新規作成 | 既存「スペリオール案内通知用」@323iztup |
| メリット | むーんの通知だけが届く。混ざらない | 作成不要ですぐ使える |
| 注意 | 作成に5分ほど | **broadcastだとSUPERIORスタッフにも届く**→必ず通知先ID(LINE_TO)で自分だけに絞る |

> 迷ったら **A案** が安全です。以下はA案の手順（B案は★の部分だけ読み替え）。

### STEP L1. LINE公式アカウント＋Messaging APIを用意（A案）
1. https://developers.line.biz/console/ にMOONのアカウントでログイン
2. プロバイダー（例：`claude用`）→ **新規チャネル → Messaging API** を作成（名前例：むーん採用通知）
3. 「Messaging API設定」タブ → **チャネルアクセストークン（長期）** を発行してコピー（**長い文字列の方**）
4. 同ページのQR/友だち追加リンクから、**MOON自身がこのアカウントを友だち追加**しておく

★B案の場合：既存@323iztupのチャネルアクセストークン（長期・長い方）を使う。superior-adminのCloudflareシークレット `LINE_CHANNEL_ACCESS_TOKEN` と同じもの。

### STEP L2. トークンを Code.gs に貼る
`Code.gs` 冒頭の CONFIG：
```js
LINE_CHANNEL_ACCESS_TOKEN: '（発行した長期トークン）',
LINE_TO: '',   // まずは空でOK（＝友だち全員にbroadcast）
```
- **A案**：友だちはMOONだけなので `LINE_TO` は空のままでOK（自分だけに届く）
- **B案**：`LINE_TO` は必ず入れる（空だとSUPERIORスタッフ全員に届く）。superior-admin管理画面の「LINE通知」設定に出ている受信ID候補＝MOON自身のIDを貼る

保存する。

### STEP L3. LINEだけ先にテスト
1. Apps Scriptエディタ上部の関数プルダウンで **`testLineOnly`** を選ぶ
2. **実行** → 初回は権限承認
3. 自分のLINEにテスト通知が届けばOK。実行ログに `HTTP 200` と出れば成功
   - `HTTP 401` → トークンが違う（短い方を貼ってないか／長期の長い方に）
   - `HTTP 400` → LINE_TO のIDが不正

### STEP L4. 反映（再デプロイ）
コードを変えたので、公開版に反映するため再デプロイします（URLは変わりません）：
**デプロイ → デプロイを管理 → 鉛筆マーク（編集）→ バージョン「新バージョン」→ デプロイ**

これで、サイトから応募 → メール＋シート＋LINE の3つに届きます。
